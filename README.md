# QTD Games - Fake Lib Module

> **Lưu ý:** Module được chia sẻ hoàn toàn **MIỄN PHÍ**. Nếu bạn thấy hữu ích, hãy để lại **1 ⭐ Star** để ủng hộ tác giả nhé!

---

## 🚀 Tính Năng 

### 👁️ Visual 
* **ESP Hero** - Hiện thông tin/vị trí Tướng
* **ESP Monster** - Hiện thông tin/vị trí Quái

### ⚔️ Combat
* **Camera View / Lock Camera** - Tùy chỉnh & Khóa góc nhìn Camera
* **Show Cooldown** - Hiển thị thời gian hồi chiêu
* **Auto Punish / Auto Execute** - Tự động Trừng phạt / Kết liễu
* **Macro Sell** - Bán đồ nhanh (Macro)
* **Mod Skins / Fix SSS** - Tùy chỉnh Skin & Sửa lỗi SSS
* **Mod Button** - Tùy biến phím bấm
* **Kill Notification** - Thông báo hạ gục tùy chỉnh
* **Evo5 Skin** - Hỗ trợ Skin Tiến Hóa Cấp 5
* **Unlock Profile** - Mở khóa hồ sơ
* **Check Report** - Kiểm tra trạng thái tố cáo
* **Logout Account** - Đăng xuất tài khoản nhanh
* **Unlock FPS** - Mở khóa tốc độ khung hình 
* **Aim Skill 1/2/3** - Hỗ trợ định hướng Chiêu 1, 2, 3

### 🏰 PVE
* **Buff Win/Lose** - Hỗ trợ PVE

### 🤖 Auto 
* **Hide UID** - Tự động ẩn UID tài khoản
