## 🚀 Tính Năng

### 👁️ Visuals (ESP)
* **ESP Hero** – Hiện thông tin/vị trí Tướng
  * Hero Line – Đường kẻ tới Tướng
  * Hero Box – Khung bao quanh Tướng
  * Hero HP & EP – Hiển thị Máu & Năng lượng
  * Hero Name – Hiển thị tên Tướng
  * Hero Level – Hiển thị cấp độ Tướng
  * Hero Visible Check – Kiểm tra khả năng nhìn thấy Tướng
* **ESP Monster** – Hiện thông tin/vị trí Quái
  * Monster Line – Đường kẻ tới Quái
  * Monster Box – Khung bao quanh Quái
  * Monster HP – Hiển thị Máu Quái
  * Monster Name – Hiển thị tên Quái
  * Monster Visible Check – Kiểm tra khả năng nhìn thấy Quái
* **ESP Minimap** – Hiển thị vị trí trên bản đồ nhỏ
* **Tùy chỉnh Offset**
  * Minimap Offset X / Y
  * ESP Offset X / Y
